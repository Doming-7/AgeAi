## 💡 What It Does

Enter your age and click **Submit** — the app sends your age to an AI and returns a fun, personalized response about what that age means: milestones, fun facts, life stages, and more.

---

## 🚀 Features

- Clean, minimal input form
- Submits age to an AI API
- Displays AI-generated response instantly
- Lightweight — no frameworks beyond Bootstrap
- Fully responsive

---

## 🛠️ Built With

| Technology | Purpose |
|------------|---------|

| JavaScript (vanilla) | Logic & API calls |
